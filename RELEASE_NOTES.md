# Loreum Lite 0.3.5 beta

The first public beta provides a local, read-only Codex source inventory with All sources search, category tabs, source excerpts, optional project scope, hook definitions, and sampled usage. Page accents follow their tab dots. A startup loader and Retry make initial loading visible.

This beta is intended for Codex desktop on macOS with Node available. Another machine's installation and other hosts/platforms remain unverified. Installed plugin discovery depends on the optional Codex CLI lookup; managed/session overrides and exact loaded model context are outside the viewer's coverage.

Report installation problems or missing source types through repository issues, using redacted examples. See the root README for installation, requirements, and privacy boundaries.
